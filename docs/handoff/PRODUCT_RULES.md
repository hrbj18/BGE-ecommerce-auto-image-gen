# 稳定产品规则

## 用户工作流

- 用户上传 1-5 张参考图，输入产品名称与希望强调的卖点，可选平台和输出语言。
- AI 扩写必须以本次图片、产品名称和用户卖点为依据，补全人群、类目、具体卖点和逐图规划；不得复制占位语或历史商品内容。
- 用户一次提交后等待完整结果。内部可以重试、降并发、跨已配置供应商恢复和补图；可恢复波动在界面显示为等待/恢复而非明显终态失败，不把技术状态拆成要求用户理解的多步流程。自动预算耗尽后才提供原任务“继续生成”。
- 历史任务统一展示状态、生成时间、提示词导入、成品入口和删除。删除任务按现有合同同时清理对应输入与输出，不误删同名其他任务。

## 账号与积分

- 所有生图必须经过用户门户登录或后台工作台权限校验；禁止开放 React 根路径或匿名 Node 写接口，内部令牌缺失时服务必须锁定而非回退本机免鉴权。
- 所有正常启用且未删除的用户都可登录门户工作台；是否关联门户角色不得成为二次登录门槛。自助注册用户仍不得获得若依后台菜单。
- 注册与登录的密码长度合同统一为 6–32 位。账号首次建立积分账户时只赠送一次体验积分，重复登录、重复初始化和重复执行数据库脚本不得再次赠送。
- 套图数量和输出清晰度共同决定整单积分价格，页面必须在提交前展示价格。价格、余额和结算以服务端为准，客户端不得自行扣分或修改价格。
- 提交时冻结整单积分；零图交付全退，部分交付按实际图片数量结算并退回差额，原任务补图只收取未结算部分。相同幂等键、重复轮询或重复终态通知不得重复扣分或退款。
- 当前充值采用用户申请、管理员人工审核到账。管理员可查询账户、调整余额、审核充值和维护价格；余额不得为负，同一充值申请只能审核一次，所有变动必须写入不可变流水。

## 输出合同

- 默认生成 5 张 1:1 主图和 8 张 9:16 详情页，除非产品规格被正式修改。
- 每张图必须有独立销售任务、场景/状态/构图和可见证据；不能只换背景或标题。
- 同一商品身份必须稳定：颜色、结构、比例、材质、图案、包装、Logo 和关键细节以本次参考图为最高事实来源。
- 辅助人物、手部、道具、环境、结构图和视觉隐喻必须服务卖点。产品可以按卖点决定出场大小或不出场，但不能被无关元素替代。
- 用户明确卖点必须被覆盖；未提供的尺寸、认证、参数、价格、销量和功效不得虚构。
- 新增营销文字及其标点、标签和底板必须完整位于画布安全区，不能因平台风格、右侧排版或长标题而出现裁切、截断、挤压、拆字或贴边；系统审核命中后只返工问题图片，首次修复仍越界时使用更保守的左侧布局再返工一次。

## 平台与语言

- 平台只控制构图气质、信息密度、视觉节奏和平台禁用项。
- 新任务只公开国内通用、国外通用，默认国内通用；未知或旧专属平台值必须明确拒绝。旧八个平台配置仅保留用于历史任务读取与续跑，不再进入用户选择。
- 语言只控制新增可见营销文案。公开支持简体中文、English、日本語、한국어、Español、Français、Deutsch、Italiano、Português、العربية；每套新增文案只能使用用户选择的目标语言，未知语言不得静默回退。
- 日本語、韩语、西班牙语、法语、德语、意大利语、葡萄牙语和阿拉伯语复用 English 的分镜结构与营销语义，但 English 只作为内部本地化源，不得直接画入成品；阿拉伯语使用 RTL 阅读顺序和正确连字，不镜像商品、Logo 或包装。
- 商品本体原有包装字、Logo 和标签可原样保留，不算营销文案混排。
- 原始商品名用于任务记录；可见展示名按输出语言生成，不能出现中文商品名配英文营销页等不一致结果。

## 安全和质量

- 禁止历史提示词、案例商品、其他品类、平台水印、二维码、虚假认证、虚假评价和错误文字污染当前任务。
- 优秀案例和提示词资料只学习结构、节奏、构图、光影和证明方式，不复制品牌、商品事实、参数或文案。
- 部分图片失败时只补失败项并保持已通过图片，目标仍是交付完整套图。
