## 当前风险

- GitHub 仓库默认保持私有；公开发布、开源许可证、密钥托管和真实演示素材仍需单独决策。
- `src/openai-image-generator.ts` 与 `scripts/local-web-server.mjs` 体量很大，修改前必须先用 `rg` 定位，不要整文件加载或顺手重构。
- 真实生图速度、文字正确率和最终视觉质量仍受所选上游模型影响；自动测试只能验证流程合同，不能替代实图验收。
- 原整批超时被错误限制为 5 分钟的问题已修复。当前 5 路首发与 2 路恢复/返工是稳定基线，仍需在更多 SKU 上观察真实首图耗时、429 比率和返工成本，再决定是否上调。
- 真实成品仍可能保留参考包装本身已有的功效文案；审核将商品本体文字视为来源事实豁免，最终上架合规仍应由业务方确认。
- 多模型控制面板/配置是否完整落地应以实际代码和 UI 为准，不从历史对话推断。
- 真实供应商速度和物理双机体验尚未在本轮验证；当前结论是“可进入少量人员、有人值守的私网内测”，不是公网生产就绪。

## 下一步优先级

1. 新任务先用本 handoff 路由定位，不再依赖长聊天历史。
2. 功能改动后运行相关测试、`npm run typecheck` 和 `npm run handoff:audit`。
3. 下一轮用第二个不同类目 SKU 复测首图耗时、429 比率、审计命中率和自动返工成本；在至少两个 SKU 数据稳定前，不把视觉审核改为严格阻断或上调 5 路基线。
4. 每次推送前运行 `pnpm run release:audit`；任何公开发布都必须重新做素材授权和许可证审查。
