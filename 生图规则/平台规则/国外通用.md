# 国外通用

规则版本：v1

## 平台职责

本规则用于没有指定海外平台时的跨境商品图，只控制视觉风格，不控制新增文案语言。主体锁定、文字安全区、卖点证明矩阵、独立场景和构图去重继承《公共核心规则》。

## 视觉合同

- 商品优先、跨市场可理解、品牌中性，不复制 Amazon、TikTok Shop、Shopee 或 Lazada 的专属界面语言。
- 使用清楚轮廓、自然材质、克制留白、真实生活方式和少量功能标注建立信任。
- 信息密度中低，每屏一个主购买理由，辅助道具必须直接证明用途、尺度或使用方式。
- 允许棚拍、手部操作、生活方式、结构近景和多角度组合，但套图内不得重复同一姿态。

## 禁用项

- 禁止平台水印、平台 UI、评分星级、评论截图、价格、折扣、销量、虚假认证和不受支持的参数。
- 禁止根据“国外”自动使用英语；新增可见文案只服从用户选择的语言规则。
