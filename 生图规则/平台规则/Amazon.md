# Amazon

规则版本：v3

## 平台职责

本规则只控制 Amazon 商品图的画面风格，不控制语言，不重复定义公共质量能力。主体锁定、卖点证明矩阵、不同形态、独立场景和构图去重必须继承《公共核心规则》。

## 平台画面风格

- 适合 Amazon marketplace 商品图、精简 A+ 风格详情图和海外货架浏览。
- 画面要 clean、credible、product-first，优先突出商品清晰度、功能证据、真实生活方式可信度和购买信心。
- 构图密度低于国内平台，留白更充足，少用装饰，多用产品、手部、生活场景和局部细节来证明卖点。
- 可以使用人物、手部操作、局部放大图、简洁 callout、轻量箭头和结构拆解，但每个元素都必须服务具体卖点。
- 不允许因为 Amazon 风格而减少卖点差异化；5 张主图仍然必须是不同产品形态、不同动作、不同视角或不同证明方式。

## 信息密度

- 每张图最多三层信息：短标题、短副标题、少量功能 callout。
- 标题要直接描述消费者价值，避免国内式大字堆叠、促销语气和复杂标签墙。
- 文案要和画面证据绑定，不能用空泛口号替代产品证明。
- 详情页可以分屏说明功能，但每屏保持干净留白，不做满屏参数表、杂乱拼贴或过度装饰。

## Amazon 差异化执行

- 主图可更克制，但不能 5 张都做成同一静物摆拍。
- 功能证明图要优先使用真实动作、局部细节、简洁标注和生活方式场景。
- 对垃圾袋、雨伞、杯子、椅子、鞋服、机器人等商品，必须继承公共核心规则中的“同一主体不同形态”逻辑。
- 允许保留原包装上的中文或原始文字，但新增营销文案必须服从语言规则。

## 禁用项

- 禁止 Best Seller、Amazon Choice、rating stars、fake reviews、price、coupon、sales volume、platform watermark、unsupported certification claims。
- 禁止国内平台促销贴纸、夸张爆炸贴、低价话术、随机乱码、错误文字、虚假对比实验和未提供参数。
- 禁止把平台名称、规则名称、内部判断过程、AI 扩写说明或 prompt 字段画进图片。
