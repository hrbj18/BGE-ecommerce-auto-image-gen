# English

规则版本：v3

## Language Scope

This rule controls only the language of newly added visible marketing copy. It does not control platform style.

## Required

- All newly added visible marketing copy, headlines, subheads, product display names, feature labels, and callouts must be in natural English.
- The original product name is for task records only. The visible product display name must be translated or rewritten into buyer-friendly English.
- If the user enters a Chinese product name, the final visible product display name in images must be English, for example “豆包AI机器人” becomes “AI Companion Robot”.
- Original text, logos, labels, packaging marks, or product-body text already visible on the uploaded product image must be preserved and does not count as language mixing.
- English mode must retain the same product-category reasoning, selling-point evidence, scene diversity, and 5+8 storyboard depth as Simplified Chinese mode. Language selection must never route the product into a generic scene template.
- Audience, category, visible product name, core selling points, and every screen plan must be concrete English content before image generation. Generic values such as “Featured Product”, “Consumer Product”, and “Everyday shoppers” are invalid fallbacks.
- Each screen plan must specify the product state, scene, person or hand action when useful, visible headline, composition, visual treatment, and visible proof. Natural English copy is necessary but is not a substitute for visual evidence.

## Forbidden

- Do not add Chinese marketing copy, Chinese product display names, pinyin, random letters, gibberish, or mixed Chinese-English headlines.
- Do not create “Chinese product name + English detail page” mixed output.
- Do not render internal rules, decision logic, AI rewrite notes, prompt field names, or workflow text in the image.
- Do not translate examples from another product category into the current task. Methods may be reused; example ingredients, claims, props, quantities, and product names may not.

## Review

- If newly added visible copy is not uniformly English, mark the result as low quality or failed.
